Philippine Standard Geographic Code (PSGC) API Documentation  
 
Overview
The Philippine Standard Geographic Code (PSGC) API provides access to the official geographic classification system of the Philippines. This API enables users to retrieve comprehensive information about the country’s regions, provinces, cities, municipalities, and barangays, all organized according to the official PSGC codes.

The API supports multiple PSGC versions, reflecting updates and administrative changes over time. This makes it suitable for applications that require accurate, authoritative, and up-to-date geographic data.

Key Benefits
Integrate official geographic reference data into web and mobile applications.

Perform statistical and demographic analysis using standardized location codes.

Track changes in administrative boundaries and subdivisions across PSGC versions.

Ensure consistency in reporting, mapping, and data interoperability across systems.

For more information, visit the official PSA PSGC page: https://psa.gov.ph/classification/psgc.

Versioning
The PSGC is regularly updated to reflect changes in geographic classifications. The API supports accessing different versions, which can be specified in the URL. Future versions will be added as updates occur.
